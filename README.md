# Groww Pocket

A prototype of Groww for first-time investors aged 20–26.

**Live:** https://groww-pocket.vercel.app

- **Money in:** invest when money actually lands (stipend, gig, gift), not on a fixed SIP date
- **Vibe check:** paste a stock tip and see its red flags
- **Why I bought:** one line of reasoning plus a short cool-off before risky buys
- **Future you:** what a spend could become if invested instead
- **Practice mode:** ₹1,00,000 of fake money to learn on

All data is mock and stays in your browser.

## Run locally

```bash
npm install
npm run dev
npm test   # evals
```

See `docs/PROMPTS.md` and `docs/EVALS.md`.
